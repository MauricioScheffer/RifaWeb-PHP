# 🎟️ Gerador de Rifas - PHP

Sistema simples desenvolvido em PHP, HTML, CSS e JavaScript para geração dinâmica de rifas (bilhetes) para ações entre amigos.

## 📌 Sobre o Projeto

O projeto permite que o usuário informe a quantidade de rifas desejada e o sistema gera automaticamente os bilhetes numerados na tela.

Os dados do prêmio são definidos via PHP e exibidos dinamicamente no HTML utilizando integração com JavaScript.

## 🚀 Funcionalidades

- Definição de prêmio via PHP
- Definição do valor da rifa
- Geração dinâmica de bilhetes
- Numeração automática
- Layout estilizado com CSS
- Manipulação de DOM com JavaScript

## 🛠️ Tecnologias Utilizadas

- PHP
- HTML5
- CSS3
- JavaScript
- Google Fonts (Poppins)

## 📂 Estrutura do Projeto

├── img/
├── rifa.php
├── rifa.css
├── teste.php

## 💡 Como Funciona

1. O usuário informa a quantidade de rifas desejadas.
2. O JavaScript captura o valor.
3. O sistema gera automaticamente os bilhetes numerados.
4. As informações do prêmio são exibidas via variáveis PHP.

## 🎯 Objetivo

Projeto desenvolvido para praticar integração entre:

- PHP (backend simples)
- HTML/CSS (estrutura e layout)
- JavaScript (interatividade)
